## 1. Cellpose-Based Cell Segmentation

Cell segmentation is performed using [Cellpose](https://www.cellpose.org/) (Stringer et al., 2021) on the DAPI channel.

In this workflow, cyclic immunofluorescence images are stored as NumPy arrays. The first DAPI image is accessed using:

```python
image[0, 0, :, :]
```

The resulting segmentation masks and corresponding intensity images are saved as separate NumPy arrays.

### Segmentation Masks

The DAPI-derived cell segmentation masks are saved as `TMA_masks.npy`:

```python
np.save(
    os.path.join(save_dir, f"{base}_masks.npy"),
    masks
)
```

### Intensity Images

The intensity images for the remaining staining channels, excluding DAPI, are saved as `TMA_intensity.npy`:

```python
np.save(
    os.path.join(save_dir, f"{base}_intensity.npy"),
    intensity_images
)
```

These outputs are used in downstream analyses, including cellular feature extraction and spatial characterization.

## 2. Segmentation Mask Extraction

This step generates additional masks from the DAPI segmentation masks and the original intensity images using [scikit-image](https://scikit-image.org/) (van der Walt et al., 2014).

### 2.1. Overlap Mask

An overlap mask is generated by intersecting the DAPI mask, which generally contains the largest number of detected cells, with the DAPI mask from the final imaging cycle, which may contain fewer detectable cells due to tissue degradation.

```python
overlap = (
    DAPI_file & (b_last_cycle_DAPI > 0)
).astype(bool)
```

A watershed segmentation is subsequently performed on the overlapping region.

### 2.2. Expanded Cell Mask

Following watershed segmentation, the detected nuclei are expanded by 15 pixels to approximate the cell body boundaries.

```python
expanded_overlap = expand_labels(
    seg1,
    distance=15
)
```

### 2.3. Cell Body Mask

A cell body mask is generated by identifying the expanded regions outside the original overlap mask, thereby excluding the nuclei.

```python
cell_body_mask = (
    (expanded_overlap > 0) & (overlap == 0)
)
```

### 2.4. Saving the Masks and Intensity Images

The generated masks and the original DAPI masks are saved as NumPy arrays:

```python
np.save(
    os.path.join(output_dir, f"{file_prefix}_cell_body_mask.npy"),
    cell_body_mask
)

np.save(
    os.path.join(output_dir, f"{file_prefix}_expanded_overlap.npy"),
    expanded_overlap
)

np.save(
    os.path.join(output_dir, f"{file_prefix}_overlap_mask.npy"),
    overlap
)

np.save(
    os.path.join(output_dir, f"{file_prefix}_dapi_masks.npy"),
    DAPI_file
)
```

To reduce storage requirements, the DAPI channel is excluded from the saved intensity image:

```python
np.save(
    os.path.join(output_dir, f"{file_prefix}_int_img_wo_DAPI.npy"),
    Int_Img_File[:, 1:, :, :]
)
```

## 3. Region Property Extraction

Cellular morphological and intensity features are extracted using `regionprops_table` from scikit-image.

The overlap mask serves as the cell-label image, while the intensity image provides the pixel values used to calculate the relevant measurements. Depending on the analysis, the intensity image can represent the raw DAPI channel or another staining channel.

```python
props = regionprops_table(
    labels,
    intensity_image=raw_dapi,
    properties=[
        "label",
        "centroid",
        "orientation",
        "axis_major_length",
        "axis_minor_length",
        "area",
        "eccentricity",
        "perimeter",
        "mean_intensity",
    ]
)
```

The extracted features include:

- **Cell identification:** label
- **Spatial position:** centroid coordinates
- **Morphology:** orientation, major and minor axis lengths, area, eccentricity, and perimeter
- **Signal intensity:** mean intensity

These measurements form the basis for subsequent cellular characterization and spatial analyses.

## 4. UNIform Image Normalization

UNIform normalization (Wang et al., 2025) is used to normalize mean intensity measurements. This method was selected because it is specifically designed for multiplex imaging data.

Normalization helps improve comparability of marker intensities across images and staining channels, supporting downstream biomarker analysis and clustering.

## 5. K-Means Clustering and UMAP Visualization

K-means clustering is applied to cellular feature data to identify groups of cells with similar characteristics. The clustering workflow follows the scikit-learn implementation (Pedregosa et al., 2011).

The silhouette score is used to assess clustering quality and help evaluate the separation between clusters.

Uniform Manifold Approximation and Projection (UMAP; McInnes et al., 2018) is then used to visualize the high-dimensional cellular feature space in a lower-dimensional representation.

GPU-accelerated UMAP implementations, such as `cuml.UMAP`, can substantially improve computational speed but were not used in this analysis.

## 6. Z-Score-Based Feature Analysis

Z-scores are calculated to identify features that deviate from the mean within each cluster. This analysis highlights biomarkers that are relatively enriched or depleted in different cellular populations.

The resulting feature profiles are used to identify biologically relevant markers and support the interpretation and labeling of clusters.

## 7. Spatial Metrics

Spatial relationships between cellular populations are evaluated using [Squidpy](https://squidpy.readthedocs.io/) (Palla et al., 2022).

The analysis includes:

- **Neighborhood enrichment:** assesses whether particular cell types are found near one another more or less frequently than expected.
- **Centrality:** characterizes the relative importance or connectivity of cell populations within spatial neighborhoods.
- **Co-occurrence:** evaluates how the spatial association between cell types changes with distance.
- **Ripley statistics:** characterize spatial distributions and clustering patterns across spatial scales.

These metrics provide complementary information about the organization of cellular populations within the tissue microenvironment.

**Reference:** Palla et al. (2022). [Squidpy documentation](https://squidpy.readthedocs.io/)

## 8. Spatial Clustering Analysis

Spatial clustering is performed using [CellCharter](https://cellcharter.readthedocs.io/en/latest/index.html) (Varrone et al., 2024), following its documented workflow.

Unlike clustering based exclusively on cellular features, this approach incorporates positional information to identify spatial domains within the tissue. The analysis identifies three spatial domains.


### Model Selection and Validation

A Gaussian Mixture Model (GMM) is used to determine the number of clusters. The Bayesian Information Criterion (BIC) is used to assess model fit and guide the selection of the number of clusters.

Cluster stability scores are used for validation, and an elbow curve is generated to visualize the selection process.

### Biomarker Characterization

The Z-score-based feature analysis described in Section 6 is subsequently applied to characterize the identified spatial clusters. This analysis supports the identification of enriched biomarkers and the interpretation of the three broader spatial categories.

**Reference:** Varrone et al. (2024)

## 9. Cliff's Delta Effect Size Analysis

Cliff's delta is used to quantify the magnitude and direction of differences between two groups.

Unlike statistical significance tests, which evaluate evidence against a null hypothesis, Cliff's delta measures the degree of separation between two distributions using a nonparametric effect size.

This analysis complements statistical testing by distinguishing differences that are not only statistically significant but also potentially meaningful in magnitude.

## 10. XGBoost Classification

[XGBoost](https://xgboost.readthedocs.io/) (Chen & Guestrin, 2016) is used to predict TNM staging categories from the extracted cellular and tissue-level features.

XGBoost is a scalable gradient-boosted decision tree framework suitable for structured data. In this pipeline, it provides a supervised learning approach for investigating associations between quantitative tissue characteristics and TNM stage.

## 13. Clark–Evans Spatial Clustering Analysis

The Clark–Evans nearest-neighbor analysis is used to characterize spatial point patterns and assess whether cells exhibit clustering, regular spacing, or an approximately random spatial distribution.

The Clark–Evans aggregation index compares the observed mean nearest-neighbor distance with the expected distance under a spatially random reference model.

This provides a complementary measure of spatial organization alongside the pair correlation function and other spatial metrics.
